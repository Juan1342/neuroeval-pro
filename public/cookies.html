1. Qué son estas tecnologías

Las cookies son pequeños archivos que un sitio puede almacenar en el navegador. También pueden utilizarse tecnologías similares, como almacenamiento local (localStorage), almacenamiento de sesión (sessionStorage), IndexedDB, píxeles o identificadores de SDK. Esta política explica el uso conocido en NeuroEval Pro y debe leerse junto con la Política de Privacidad.

2. Tecnologías identificadas en el código

  • Preferencia de idioma: la aplicación guarda la preferencia de idioma en localStorage con la clave neuroeval-language.
  • Progreso de actividades: el código guarda determinados datos de progreso local en el navegador. La clave se genera por la función de progreso de la aplicación; debe verificarse en el inventario técnico final.
  • Firebase Authentication: la aplicación utiliza el SDK web de Firebase para iniciar y mantener sesiones. El SDK puede usar mecanismos del navegador, como IndexedDB u otros almacenamientos, según la configuración y el navegador. Debe verificarse el comportamiento real de persistencia.
  • Google Fonts: se solicitan recursos tipográficos a Google Fonts, lo que puede transmitir datos técnicos como dirección IP y datos del navegador a Google.
  • Tailwind CDN: la interfaz carga el script de Tailwind desde un CDN externo, que recibe solicitudes técnicas del navegador.
  • Wompi: el widget de checkout se carga cuando el usuario llega al proceso de pago. Wompi y los proveedores involucrados pueden utilizar tecnologías necesarias para prestar, proteger y procesar el pago, de acuerdo con sus propios avisos.

3. Finalidades

Las tecnologías locales conocidas permiten recordar el idioma y conservar progreso de actividades. Los mecanismos de autenticación permiten mantener la sesión y proteger la cuenta. Los recursos externos permiten mostrar tipografías, estilos y el proceso de pago. No se ha identificado en el código revisado una integración deliberada de publicidad comportamental ni un píxel publicitario; esta afirmación debe volver a comprobarse en el navegador antes de publicar.

4. Cookies estrictamente necesarias y tecnologías opcionales

Las tecnologías necesarias para autenticar, proteger la cuenta, prevenir fraude y ejecutar el pago pueden ser indispensables para prestar la función solicitada. Las preferencias de idioma y progreso mejoran la experiencia, pero pueden borrarse desde el navegador, lo que podría restablecer preferencias o eliminar el progreso local. La clasificación final de cada tecnología y la necesidad de consentimiento previo dependen de la jurisdicción y deben validarse jurídicamente.

5. Cómo gestionar el almacenamiento

Puedes revisar, bloquear o eliminar cookies y datos de sitios desde la configuración del navegador. Si bloqueas almacenamiento necesario, el inicio de sesión, la continuidad de sesión, el progreso o el checkout pueden dejar de funcionar correctamente. Eliminar datos del navegador no necesariamente elimina la información almacenada en los servidores de NeuroEval Pro; para ejercer derechos sobre esos datos consulta la Política de Privacidad.

6. Proveedores externos

Los recursos identificados incluyen Google Fonts, Tailwind CDN, Firebase Authentication y Wompi. Sus tecnologías y tratamientos se rigen también por sus avisos y condiciones. Antes de publicación deben documentarse las URLs exactas, finalidades, categorías de datos, duración, ubicación y mecanismo de consentimiento aplicable. Proveedor de analítica/cookies adicional: no identificado en el código revisado; confirmar con una inspección de red del sitio desplegado.

1. What these technologies are

Cookies are small files a website may store in a browser. Similar technologies include local storage, session storage, IndexedDB, pixels and SDK identifiers. This policy describes the known use in NeuroEval Pro and should be read with the Privacy Policy.

2. Technologies identified in the source code

  • Language preference: the application stores the selected language in localStorage under the key neuroeval-language.
  • Activity progress: the code stores certain activity progress data locally in the browser. The key is generated by the application's progress function and must be verified in the final technical inventory.
  • Firebase Authentication: the application uses the Firebase web SDK to sign in and maintain sessions. Depending on configuration and browser, the SDK may use IndexedDB or other browser storage. Actual persistence must be verified.
  • Google Fonts: font resources are requested from Google Fonts, which may receive technical data such as IP address and browser information.
  • Tailwind CDN: the interface loads the Tailwind script from an external CDN, which receives technical browser requests.
  • Wompi: the checkout widget is loaded when a user reaches payment. Wompi and involved providers may use technologies necessary to provide, secure and process payment under their own notices.

3. Purposes

Known local technologies remember language and activity progress. Authentication mechanisms maintain sessions and protect accounts. External resources provide fonts, styling and payment checkout. No deliberate behavioral-advertising integration or advertising pixel was identified in the source code reviewed; this must be checked again in the browser before publication.

4. Strictly necessary and optional technologies

Technologies required to authenticate, secure accounts, prevent fraud and process payments may be necessary to provide the requested feature. Language and progress preferences improve the experience but may be deleted through browser settings, which can reset preferences or remove local progress. Final classification and prior-consent requirements depend on applicable law and require legal review.

5. Managing storage

You can review, block or delete cookies and site data in your browser settings. Blocking necessary storage may prevent sign-in, session continuity, progress saving or checkout from working correctly. Deleting browser data does not necessarily delete information stored on NeuroEval Pro servers; use the Privacy Policy to exercise rights over that data.

Identified resources include Google Fonts, Tailwind CDN, Firebase Authentication and Wompi. Their technologies and processing are also governed by their own notices and terms.
